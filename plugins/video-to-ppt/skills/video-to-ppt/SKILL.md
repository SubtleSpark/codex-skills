# 视频课件还原

将 URL 或本地视频中的已有课件画面整理为 `.pptx`，一张课件图片对应一页。保留原画面文字、图表和顺序，不根据字幕重新创作课件，不承诺恢复可编辑文字或原始动画。

## 开始与工具边界

确认输入、输出目录和用户指定的时间段。默认处理单个视频、完整时段，输出到当前任务目录的新子目录，避免把媒体放进 Skill 源码库。只下载或只要字幕的请求在相应阶段结束。已有本地视频、字幕直接复用。

按实际路径检查所需能力：URL 下载优先 `yt-dlp`；媒体检查与抽帧优先 `ffmpeg`、`ffprobe`；附带抽帧脚本使用 Python 3.12+ 标准库；PPT 制作与预览使用宿主已有 presentation Skill 或可用的本地制作及渲染工具。先确认这些能力真实可用，再开始完整流水线。仅下载字幕不要求 PPT 工具。

这些是工具选择建议，不是固定平台依赖。可以使用用户指定或环境中已具备的等价工具。缺少所需工具、运行时或渲染能力时，简短说明缺什么、用于哪一步、建议如何安装，然后停止，保留已有产物并说明续跑位置。**不自动安装、升级、下载运行时或模型，不临时联网拉包，也不在失败后私自换工具硬跑。** 安装建议遵守当前机器的工具管理约定。字幕不存在、无目标语言或字幕不可获取是可选项缺失：提示并跳过字幕，视频下载及 PPT 继续；不自动转写。

读取浏览器登录态前确认本次任务已有授权及浏览器选择。旧任务授权不自动适用于新任务。需要登录而尚未授权时询问用户；可以先完成不依赖登录的阶段。通过工具读取登录态，不导出 Cookie 文件，不把凭据或带签名的媒体地址写入交付记录。

## 1. 获取视频和可用字幕

URL 输入先读 [下载参考](references/download.md)。检查清晰度和字幕清单，按当前返回结果选择格式和语言，不沿用其他视频的格式 ID。默认最高不超过 1080p，用户指定时遵从指定。记录标题、公开来源 URL、视频 ID、时长、实际清晰度和字幕类型。

分别执行视频下载和字幕下载，使字幕失败不会中断主流程。下载后用 `ffprobe` 核对视频可解码、时长及所需音轨；字幕须有实际正文，弹幕不是字幕。保留原始字幕，缺失则在交付中说明。视频下载失败时保留部分文件和错误信息，停止依赖它的抽帧步骤。

## 2. 检查画面，提取候选页

先查看开头、中段和结尾的代表画面，判断课件区域、讲师窗口、播放器边框和字幕遮挡。完整课件区域清楚时可裁剪边框；裁剪会损失内容或画面布局频繁改变时，先与用户对齐。无课件的视频先说明情况，不把人像镜头硬凑成课件。

附带脚本只做候选生成，不识别课件语义。遵守宿主的 Python 运行约定，使用已安装运行时；例如已有 uv 和 Python 3.12 时离线执行：

```sh
uv run --offline --no-project scripts/extract_frames.py /absolute/video.mp4 /absolute/new-candidates
```

脚本路径相对本 Skill 目录。可用 `--interval 1` 加密采样、`--threshold 4` 提高对细微变化的敏感度、`--crop W:H:X:Y` 聚焦固定课件区域。每次调整写入新的候选目录。参数含义及限制见脚本 `--help`。

查看生成的 `contact-sheet.html` 和原分辨率 PNG。候选按时间排序，只合并连续重复页，返回旧页仍保留。逐项核对：转场、黑屏、人像、鼠标移动造成的假分页；逐条出现的文字或动画应保留该页完整状态；相似模板上的小字、公式或数字变化不能直接当重复删除。脚本输出是候选清单，不是审定页数。

结合源视频在变化密集处、候选间异常长的空档及首尾补查。调整采样或按时间戳单独抽帧补齐漏页。对于快速翻页、滚动网页、白板或持续动画，与用户对齐截取口径；不能宣称自动完整还原。把最终选择写入 `pages.json`，每项保留图片路径、源时间戳和简短取舍理由，不覆盖原始候选清单。

## 3. 组装图片 PPT 并验收

使用已确认可用的 PPT 制作能力；宿主有 presentation Skill 时按其制作与渲染流程执行。无需新增封面、目录或总结页。页面比例匹配课件主体，每页放一张原分辨率图片，保持比例、完整可见，不拉伸或裁掉边缘。字幕文件独立保留，默认不把字幕另做页面或叠加到图片。页码与时间戳写入备注或配套 `pages.json`，不遮挡原内容。

导出本地 `.pptx`，渲染并检查全部页面的顺序、比例、清晰度、黑边和裁剪，页数须与最终清单一致。自动检查不能代替看图。缺少渲染能力按工具边界停止，交付可续跑的已有文件，说明 PPT 尚未完成验收。

交付视频、实际取得的字幕、PPT 和时间戳清单的链接，简短报告页数、字幕缺失及会影响使用的漏页或清晰度限制。保留抽帧中间文件供复核，不主动删除用户素材。
